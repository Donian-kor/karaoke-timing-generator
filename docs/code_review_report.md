## 기존 보고서에서 정정한 내용

- 리뷰 범위의 Python 파일 수는 22개가 아니라 **23개**다.
- `shift_ts` 재현 결과는 잘못된 4자리 소수부를 만든다. 내장 파서는 이를 4.0초로 해석하므로, 기존 보고서의 “1초 오차” 주장은 확인되지 않았다. 확인된 문제는 비표준 출력 형식과 센티초 반올림 경계에서의 시간 손실이다.
- `SettingsSection.set_gen_enabled()` 및 `set_cancel_enabled()`는 존재하지 않는 위젯을 참조하지만 저장소 내 호출부가 없다. 현재 사용자 경로에서 발생하는 High 결함으로는 분류하지 않았다.
- DeepFilterNet 결과 선택의 수정 시각 기반 탐색은 작업별 새 임시 폴더 안에서 수행된다. 경쟁 조건이 실제로 발생한다는 근거가 확인되지 않아 결함으로 남기지 않았다.
- `audio_denoise.py`의 `amix weights` 공백 구분은 FFmpeg 필터 인수 형식만으로 파싱 실패라고 단정할 수 없어 기존 주장을 제거했다.
