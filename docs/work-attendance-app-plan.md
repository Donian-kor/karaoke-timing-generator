# 출퇴근 기록부 앱 기획서

## 1. 앱 개요

### 1.1 앱 이름 (가칭)
- **WorkLog** / **출퇴근 기록부** / **ClockIn**
- 최종 이름은 Play Store 검색 키워드 조사 후 결정

### 1.2 한 줄 설명
> 소규모 사업장(5~50명)을 위한 간편 출퇴근 기록 + 근태 관리 앱

### 1.3 핵심 가치 제안
- **종이 출석부 대체**: 수기 출퇴근 기록 → 디지털 자동화
- **급여 계산 보조**: 근무 시간 자동 집계 → 급여 계산 시 참고
- **법적 증거**: 근로시간 기록 의무(근로기준법) 대응
- **저렴한 비용**: 기존 근태 시스템(월 5~10만 원) 대비 1/10 가격

---

## 2. 타겟 사용자

### 2.1 1차 타겟 (MVP)
- **소규모 사업장 사장/관리자**
  - 직원 5~30명 규모
  - 카페, 식당, 편의점, 미용실, 학원, 소규모 공장
  - 기존 근태 시스템이 없거나 종이/엑셀로 관리 중
  - IT 지식 낮음 → 간단한 UI 필수

### 2.2 2차 타겟 (성장 단계)
- 프리랜서/용역업체 (현장 작업자 출퇴근)
- 건설 현장 (일용직 출퇴근)
- 이벤트/행사 스태프

### 2.3 사용자 페르소나

**페르소나 A: 카페 사장 김민수 (35세)**
- 직원 8명 (파트타임 6명, 정규 2명)
- 현재: 종이 출석부 + 카카오톡으로 근무표 공유
- 문제: 월말 급여 계산에 2~3시간 소요, 누락/오류 빈번
- 니즈: 출퇴근 자동 기록 + 근무 시간 자동 집계 + 급여 계산 보조

**페르소나 B: 학원 원장 박지영 (42세)**
- 강사 12명 + 행정 2명
- 현재: 엑셀로 출퇴근 관리
- 문제: 강사별 수업 시간 + 근무 시간 구분 어려움
- 니즈: 직원별 근무 시간 조회 + 월별 리포트

## 3. 핵심 기능 (MVP)

### 3.1 직원 관리
- 직원 등록 (이름, 연락처, 입사일, 시급/월급)
- 직원 목록 조회/수정/삭제
- 직원별 고유 PIN 또는 QR 코드

### 3.2 출퇴근 기록
- **출근 체크**: PIN 입력 또는 QR 스캔 → 출근 시간 자동 기록
- **퇴근 체크**: PIN 입력 또는 QR 스캔 → 퇴근 시간 자동 기록
- **근무 시간 자동 계산**: 출근~퇴근 시간 차이 (휴게 시간 제외)
- **수동 보정**: 관리자가 출퇴근 시간 수동 수정 (사유 기록)

### 3.3 근태 조회
- 일별 출퇴근 현황 (전체 직원)
- 직원별 근무 시간 조회 (일/주/월)
- 지각/조퇴/결근 자동 표시
- 근무 시간 합계 (급여 계산 참고)

### 3.4 알림
- 출근 미체크 알림 (설정 시간 이후)
- 퇴근 미체크 알림
- 근무 시간 초과 알림 (법정 근로시간)

### 3.5 리포트
- 월별 근무 시간 요약 (직원별)
- CSV/Excel 내보내기 (급여 계산용)
- PDF 리포트 생성 (선택)

## 6. 기술 스택

### 6.1 Android 앱
- **언어**: Kotlin
- **UI**: Jetpack Compose (Material 3)
- **아키텍처**: MVVM + Repository 패턴
- **로컬 DB**: Room (SQLite)
- **의존성 주입**: Hilt
- **비동기**: Kotlin Coroutines + Flow
- **알림**: WorkManager + AlarmManager
- **QR 스캔**: ML Kit Barcode Scanning
- **차트**: Vico (Compose 차트 라이브러리)

### 6.2 백엔드 (v2 이후, 클라우드 동기화)
- **옵션 A**: Firebase (Auth + Firestore + Storage) — 빠른 시작
- **옵션 B**: Supabase — 오픈소스, 비용 효율적
- **옵션 C**: 자체 서버 (Spring Boot / Node.js) — 장기적

### 6.3 결제
- Google Play Billing Library (인앱 구독)
- 구독 상태 관리: Google Play Developer API

## 7. 데이터 모델

### 7.1 핵심 엔티티

```
Employee (직원)
├── id: Long (PK)
├── name: String
├── phone: String?
├── hourlyRate: Double? (시급)
├── monthlySalary: Double? (월급)
├── pin: String (4자리 PIN)
├── qrCode: String? (QR 코드 데이터)
├── hireDate: LocalDate
├── isActive: Boolean
└── createdAt: LocalDateTime

AttendanceRecord (출퇴근 기록)
├── id: Long (PK)
├── employeeId: Long (FK → Employee)
├── date: LocalDate
├── clockIn: LocalDateTime?
├── clockOut: LocalDateTime?
├── breakMinutes: Int (휴게 시간)
├── workMinutes: Int (자동 계산)
├── isLate: Boolean
├── isEarlyLeave: Boolean
├── isAbsent: Boolean
├── note: String? (수동 보정 사유)
└── createdAt: LocalDateTime

Workplace (사업장) — v2
├── id: Long (PK)
├── name: String
├── address: String?
├── latitude: Double?
├── longitude: Double?
├── radius: Int (GPS 출퇴근 반경, 미터)
└── createdAt: LocalDateTime

Schedule (근무표) — v2
├── id: Long (PK)
├── employeeId: Long (FK)
├── date: LocalDate
├── startTime: LocalTime
├── endTime: LocalTime
└── note: String?
```

### 7.2 관계
```
Workplace 1:N Employee
Employee 1:N AttendanceRecord
Employee 1:N Schedule (v2)
```

## 10. AI 바이브코딩 가이드

### 10.1 개발 순서 (AI와 함께)

1. **프로젝트 생성**: Empty Compose Activity
2. **의존성 추가**: Room, Hilt, Navigation, WorkManager
3. **데이터 모델**: Employee, AttendanceRecord 엔티티
4. **DAO 작성**: Room DAO (insert, query, update, delete)
5. **Repository 패턴**: 데이터 접근 추상화
6. **ViewModel**: UI 상태 관리
7. **Compose UI**: 화면별 컴포저블
8. **Navigation**: 화면 전환 설정
9. **알림**: WorkManager 설정
10. **테스트**: 에뮬레이터에서 실행 확인

### 10.2 AI 프롬프트 예시

**1단계 - 데이터 모델:**
```
"Kotlin + Room으로 출퇴근 앱의 데이터 모델을 만들어줘.
Employee 엔티티: id, name, phone, hourlyRate, pin, hireDate, isActive
AttendanceRecord 엔티티: id, employeeId, date, clockIn, clockOut, breakMinutes, workMinutes, isLate, isAbsent
Room DAO 포함, Hilt로 DI 설정"
```

**2단계 - 출퇴근 체크 UI:**
```
"Jetpack Compose로 출퇴근 체크 화면을 만들어줘.
- 4자리 PIN 입력 키패드 (0-9)
- 출근/퇴근 버튼
- 현재 시간 표시 (HH:mm:ss)
- PIN 입력 시 마스킹 (●●●●)
- Material3 디자인, 다크모드 지원"
```

**3단계 - 근태 조회:**
```
"Jetpack Compose로 일별 출퇴근 현황 화면을 만들어줘.
- 날짜 선택 (DatePicker)
- 직원별 카드 (이름, 출근시간, 퇴근시간, 근무시간)
- 지각/결근 직원 하이라이트 (빨간색)
- LazyColumn으로 스크롤"
```

### 10.3 주의사항

- **한 번에 하나의 기능**만 요청
- **에러 발생 시** 전체 에러 메시지를 AI에게 전달
- **Room 마이그레이션**: 스키마 변경 시 migration 코드 필요 (AI에게 요청)
- **Hilt 설정**: 처음 설정이 복잡할 수 있음 → 단계별로 요청

## 11. 경쟁 분석

### 11.1 기존 솔루션

| 제품 | 가격 | 특징 | 약점 |
|---|---|---|---|
| 알바천국 근태 | 무료~월 3만 원 | 알바 구인 연계 | 기능 복잡, 광고 많음 |
| 시프티 (Shiftee) | 월 3,000~10,000원/인 | GPS, 사진 출근 | 인당 과금 → 소규모에 부담 |
| Flex | 월 5,000~15,000원/인 | HR 통합 | 대기업 타겟, 비쌈 |
| 종이 출석부 | 0원 | 간단 | 수기, 오류, 급여 계산 수동 |

### 11.2 차별화 포인트

1. **인당 과금이 아닌 사업장 단위 과금** → 소규모에 저렴
2. **오프라인 동작** → 인터넷 없어도 출퇴근 기록 가능
3. **간단한 UI** → IT 지식 없는 사장도 5분 안에 설정
4. **데이터 소유권** → 사용자 데이터는 사용자 폰/서버에 저장
